# Sekretär

Sekretär ist die Büro-Suite für kleine Betriebe: **Mail mit gemeinsamen Postfächern, Kalender und
Kontakte** im Browser und am Handy. Jede Firma bekommt ihren eigenen Server mit
[Stalwart](https://stalw.art); Sekretär ist die Oberfläche, mit der die Mitarbeiter arbeiten.

![Sekretär: Posteingang mit gemeinsamen Postfächern und geöffneter Mail](screenshots/mail.png)

## Was drin ist

|              |                                                                                                                                                               |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Mail**     | Ordner und Unterordner, gemeinsame Postfächer (info@, rechnung@), Archiv, Suche, Schreiben mit Formatierung, Anhänge, Antworten mit Zitat, Push ohne Neuladen |
| **Kalender** | Woche und Tag, Einladungen mit Zusage/Absage, ganztägige Termine                                                                                              |
| **Kontakte** | Kunden-Ansicht mit letzten Mails und nächsten Terminen, Anlegen und Bearbeiten                                                                                |
| **Handy**    | jede Ansicht als eigener Bildschirm mit Tab-Leiste                                                                                                            |

## Wie es weitergeht

1. **Gmail-Umzug**: Mails, Kontakte und Kalender aus Gmail übernehmen, parallel weiterarbeiten.
2. **Pilot** bei einem Kunden, vier Wochen parallel zu Gmail.
3. **Zusatzmodule**, eins nach dem anderen: Ticket-Postfach, Aufgaben mit Zeiterfassung,
   Terminbuchung, Team-Chat, Belegarchiv.
4. **Firmenverwaltung** für den Kunden-Admin: Mitarbeiter, Rechte für gemeinsame Postfächer,
   Offboarding. Bis dahin reicht Stalwarts eigene Verwaltung.
