# Sekretär

Sekretär ist die Büro-Suite für kleine Betriebe: **Mail mit gemeinsamen Postfächern, Kalender und
Kontakte** im Browser und am Handy. Jede Firma bekommt ihren eigenen Server mit
[Stalwart](https://stalw.art); Sekretär ist die Oberfläche, mit der die Mitarbeiter arbeiten.

![Sekretär: Posteingang mit gemeinsamen Postfächern und geöffneter Mail](screenshots/mail.png)

## Was drin ist

|              |                                                                                                                                                               |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Mail**     | Suche über alle Ordner mit Operatoren wie in Gmail, alle Posteingänge in einer Liste, Ordner und Unterordner, gemeinsame Postfächer (info@, rechnung@), Archiv, Suche, Schreiben mit Formatierung, Anhänge, Antworten mit Zitat, Push ohne Neuladen |
| **Kalender** | Tag, Woche, Monat und Liste, Termine per Ziehen verschieben, wiederkehrende Termine, Kalender mit Kollegen teilen, Einladungen mit Zusage/Absage               |
| **Kontakte** | Kunden-Ansicht mit letzten Mails und nächsten Terminen, Anlegen und Bearbeiten, Gruppen, vCard-Import/-Export, Adressbücher mit Kollegen teilen              |
| **Firma**    | Mitarbeiter anlegen und sperren, Passwort und Anmeldung mit Code zurücksetzen, weitere Adressen, gemeinsame Postfächer mit Lese- oder Senderecht, Abwesenheit mit Vertretung, Firmen-Signatur, Austritt mit Übergabe, Umzug von Microsoft 365, Gmail, GMX & Co., Outlook (PST) und Google-Export – für den Chef in den Einstellungen |
| **Handy**    | jede Ansicht als eigener Bildschirm mit Tab-Leiste                                                                                                            |

## Wie es weitergeht

1. **Kern ausbauen**: Mail, Kontakte und Kalender so gut machen, dass niemand etwas vermisst.
2. **Umzug abrunden**: Senden als alte Adresse während des Parallelbetriebs, einzeln geänderte
   Termine von Serien aus Microsoft 365.
3. **Pilot** bei einem Kunden, vier Wochen parallel zum alten System.
4. **Zusatzmodule**, eins nach dem anderen: Ticket-Postfach, Aufgaben mit Zeiterfassung,
   Terminbuchung, Team-Chat, Belegarchiv.
5. **Leitstand** für den Betreiber: alle Kunden-Server mit Status, Backups, Restore-Test und
   Updates an einer Stelle.
